# CFPB Consumer Complaints  Exploratory Analysis

Exploratory analysis of the U.S. Consumer Financial Protection Bureau (CFPB) Consumer Complaint Database  ~1.28M complaints filed against ~5,275 companies between Dec 2011 and May 2019.

## Dataset

Available on Kaggle: https://www.kaggle.com/datasets/selener/consumer-complaint-database

The raw `rows.csv` (~700 MB) is not committed to this repo. Download it from Kaggle and place it in a local `data/` directory, then update `DATA_PATH` in the notebook.

## Stack

- Python 3, pandas, numpy
- matplotlib for static charts
- plotly for interactive visuals

## Files

- `CFPB_Consumer_Complaints_Analysis.ipynb`  main notebook

# Source and utilities

This folder is intended for reusable Python scripts, helper modules, or data-prep utilities that support the analysis.

Current project assets are primarily notebook-based, but this area is the right place for:

- data cleaning functions
- feature engineering helpers
- reusable plotting utilities
- model training or evaluation scripts

If a script is only used in one notebook, keep it alongside that notebook until it is refactored into reusable code.
